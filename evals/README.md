# Evaluations

Gold cases are concrete bindings of reviewed task semantics to corpus evidence.

Do not add a case merely because the company name changed. Add one when it covers a new combination
that can produce a distinct failure, such as scope, period pairing, unit, evidence layout, document
version, retrieval topology, or answerability.

Scorers and software tests are intentionally not defined yet. First make the semantic contract and
its evidence-bound cases correct.
